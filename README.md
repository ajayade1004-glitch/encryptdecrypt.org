# Free Client-Side Cryptographic & Developer Tools

A collection of 100% client-side cryptographic hashing, ciphers, encoders, and developer utilities that run locally inside your browser memory. All tools adhere to official RFC and NIST FIPS specifications.

## 🚀 Core Features
- **Zero-Server Latency:** Standard ciphers execute natively via the browser's hardware-accelerated Web Cryptography API.
- **AES-256-GCM & CBC:** Secure authenticated encryption and legacy symmetric ciphers.
- **Hashing Checksums:** Instantly generate SHA-256, SHA-512, MD5, and HMAC-SHA256 digests.
- **Data Encodings:** Fully compliant RFC 4648 Base64, Hex/Base16, and URL encoder/decoder tools.
